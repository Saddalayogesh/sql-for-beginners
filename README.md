# SQL for Beginners

My coding exercise solutions for the SQL for Beginners course | Powered by TrainingMug

## About

This repository contains SQL practice problems and solutions that I solved while learning SQL fundamentals through the TrainingMug platform.

It covers beginner to intermediate SQL concepts including filtering, joins, aggregate functions, sorting, and reporting queries.

## Topics Covered

- SELECT Statements
- WHERE Clause
- ORDER BY
- LIMIT and OFFSET
- Aggregate Functions
- GROUP BY
- INNER JOIN and LEFT JOIN
- Aliases
- CASE Statements
- Pagination Queries
- CRUD-Based SQL Queries
- Database Normalization Concepts
- Filtering with BETWEEN, IN, and LIKE
- Sorting and Data Analysis Queries

## Key Learnings

- Writing optimized SQL queries
- Working with multiple tables using joins
- Performing data analysis using aggregate functions
- Understanding relational database structure
- Building real-world query logic using SQL
